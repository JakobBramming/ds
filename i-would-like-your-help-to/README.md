## Customize

Edit `index.html` if you want to add:

- GitHub or LinkedIn links
- a public CV download
- exact thesis title
- links to code repositories, reports, or demos

## Suggested project format

For each project, keep the text tight:

1. Problem: what question or challenge did the project address?
2. Method: what data, methods, models, or tools did you use?
3. Contribution: what did you personally do?
4. Result: what changed, improved, or became clearer?

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Add these files to the repository root.
3. Push to GitHub.
4. In GitHub, open `Settings` → `Pages`.
5. Under `Build and deployment`, select `Deploy from a branch`.
6. Select the `main` branch and `/root`, then save.

GitHub will publish the site at a URL like:

`https://your-github-username.github.io/repository-name/`
